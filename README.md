# ✅ ChecklistApp

Simple task checklist GUI app built with `tkinter`. Includes task tracking, remarks, reminders, and export to Excel.

---

## 🧠 Notes for Future Me

This script (`Checklist.pyw`) is meant to be compiled into a **standalone app** using PyInstaller.

### 🔧 Compile Instructions

#### 🟢 Onedir (Recommended for faster launch)
```bash
python -m PyInstaller --onedir --windowed --icon=myicon.ico Checklist.pyw
